## `08.` CONTRIBUTION_GRID.snake

<div align="center">

<img src="https://raw.githubusercontent.com/LeonardoAugustoBacelar/LeonardoAugustoBacelar/output/github-contribution-grid-snake-dark.svg" width="100%" />

</div>

<details>
<summary>⚙️ Como ativar a animação da cobrinha (clique para expandir)</summary>

<br/>

Essa animação é gerada automaticamente pela GitHub Action <a href="https://github.com/Platane/snk">Platane/snk</a>. Para ativar no seu perfil:

1. Crie o arquivo `.github/workflows/snake.yml` neste repositório com o conteúdo abaixo;
2. Aguarde a Action rodar (ela roda a cada push e também de forma agendada);
3. O SVG será publicado automaticamente na branch `output`, exatamente no caminho referenciado pela `<img>` acima.

```yaml
name: Snake Contribution Animation

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        id: snake
        with:
          github_user_name: LeonardoAugustoBacelar
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
